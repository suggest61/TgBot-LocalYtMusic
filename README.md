# TgBot-LocalYtMusic
Личный телеграм бот для скачивания музыки с ютубе без репламы и подписок


## ✨ Особенности
* **Максимальное качество** — конвертация в MP3 320 kbps.
* **Полноценные теги** — автоматическое вшивание обложки видео и метаданных (автор, название) прямо в аудиофайл через FFmpeg.
* **Безопасность** — встроенный белый список (Whitelist) по Telegram ID для ограничения доступа к боту.
* **Асинхронность** — тяжелый процесс скачивания вынесен в отдельный поток (`run_in_executor`), чтобы бот не зависал при одновременных запросах.
* **Автоочистка** — скачанные медиафайлы удаляются с сервера сразу после отправки пользователю.

## 🛠️ Стек технологий
* **Язык:** Python 3.10+
* **Библиотека бота:** Aiogram 3.x
* **Загрузчик медиа:** yt-dlp
* **Обработка аудио:** FFmpeg (требуется в системе)

## 📦 Быстрый запуск

### 1. Требования к системе
На компьютере или сервере должны быть установлены **Python 3.10+** и утилита **FFmpeg**.

* **Ubuntu/Debian:** `sudo apt update && sudo apt install ffmpeg`
* **macOS:** `brew install ffmpeg`
* **Windows:** Скачайте бинарные файлы с официального сайта FFmpeg и добавьте путь к ним в системную переменную `PATH`.

### 2. Установка
Клонируйте репозиторий и перейдите в папку проекта:
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

Установите необходимые зависимости:
```bash
pip install aiogram yt-dlp
```

### 3. Настройка переменных окружения (Environment Variables)
Бот использует переменные окружения для безопасности. Создайте их в системе или в `.env` файле:

* `BOT_TOKEN` — токен вашего бота, полученный от [@BotFather](https://t.me).
* `WHITELIST` *(опционально)* — ID пользователей Telegram через запятую, которым разрешено пользоваться ботом. Если оставить пустым, бот будет доступен **всем**.

**Пример для Linux/macOS:**
```bash
export BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
export WHITELIST="123456789,987654321"
```

### 4. Запуск бота
```bash
python bot.py
```

## 🚀 Использование
1. Напишите боту команду `/start`.
2. Отправьте ему любую ссылку на видео (например, YouTube, YouTube Shorts и др.).
3. Бот пришлет вам готовый MP3-файл с обложкой.
